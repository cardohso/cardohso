# Hi, I'm João Pedro Cardoso

**AI engineer** building and evaluating RAG and LLM systems · MSc in Software Engineering at ISEC · Portugal

I care about whether a generative AI system's answers are actually reliable, not just plausible. I build the retrieval and generation pipeline, and the testing and observability layer around it: LLM-as-a-judge evaluation, retrieval metrics, and CI gates that catch regressions before they ship.
